# 《缺席的孩子》

繁體中文互動式懸疑推理小說。玩家扮演懷孕八個月的國小導師林若晴，在休假前追查學生陳子皓反覆缺席背後的真相。

## 開始遊戲

直接雙擊 `index.html` 即可遊玩，不需要安裝套件、啟動伺服器或申請 API Key。也可將整個資料夾推送至 GitHub，於 Repository Settings → Pages 選擇分支根目錄部署。

## 操作

- 點擊劇情文字可跳過逐字顯示。
- 每章選擇一項調查行動；選擇會改變線索、信任、身體負擔與結局。
- 「線索」可開啟分類筆記本、推理桌及人物關係圖。
- 推理桌可任選 2–3 項線索驗證，並提供三級提示。
- `N` 開啟線索筆記本，`Esc` 關閉面板。
- 遊戲自動存檔，另有三個手動存檔欄位。錯誤或舊版資料會安全忽略。

## 檔案架構

- `index.html`：頁面入口，支援 `file://` 與 GitHub Pages。
- `css/style.css`：場景、小說介面、行動裝置與無障礙樣式。
- `js/story-data.js`：十二章、證據與四種結局的資料。
- `js/app.js`：遊戲狀態、渲染、推理、存讀檔與結局判定。
- `assets/characters/`：林若晴、陳子皓、陳奶奶與許文岳的原創角色立繪。
- `docs/case-bible.md`：開發用案件真相與伏筆對照（含完整劇透）。

## 設計原則

遊戲不把教師自行冒險調查設為正解；合理休息、校內評估、兒少保護通報、警方與社工合作都能推進故事。孩子的經驗以克制方式呈現，推理系統區分證詞、假說、矛盾及已驗證事實。

## 相容性

支援現代 Chrome、Safari、Firefox、Edge 與手機直式畫面。所有內容均為靜態檔案，沒有網路請求。
